# 中美脱钩观察
- 主题：2017 年以来中美脱钩进程复盘与个人体感
- 目标读者：关注产业政策、跨国企业与个人发展抉择的公众号读者
- 创建人：Codex 协助用户
- 最近更新：2024-06-XX

## 原始提示词

### 提纲
主题是，中美脱钩从17年开始已经差不多完成了，后续差不到哪里去了。引用下外贸，fdi，风险投资，留学生数量，等等各种合作数据
- 个人情绪是，我太难了，毕业不久赶上这玩意。2016毕业一转眼快十年了。
- 标志性事件是，中国长臂管辖系统，特朗普再度威胁加关税100%。压力测试已经在今年4月做完了。后续不会更差了。因为中国公司的利润率决定了，当关税超过30%，绝大部分可替换的东西已经到越南新加坡墨西哥香港转运了。
- 中国目前主要就是芯片禁运，搞信创。新凯来现在应该7nm问题不大了。这个东西没个十年很难起来，讲讲原因。已经五年了。美国也在搞稀土，这个东西也是没个三五年搞不起来。多产业均摊产业链成本是很重要的事情。美国的软件，中国的制造，都有大量的小作坊，市场足够小，足够深耕，只有多产业一起才能养活。如果双方都学习微软和民主党的小院高墙策略：个人用户放任盗版，让产研发展不起来。双方都觉得恶心双方
- 新加坡外交部马凯硕的判断很重要，近期有个演讲，说明了同样的观点

### 人设
- 一个16年毕业的程序员，尽可能用互联网相关的兴衰案例。22年之前在北京，22年之后在新加坡。
- 12-16年，北邮，各种实习。大几岁的发展比较成功的范式是：能拿到全球机会却选择在中国本地的美式制度的公司的一帮人。
- 16-18年，LinkedIn，见证美资企业逐步退出中国。18-20，小马智行，见证资本市场关闭IPO和审计底稿事件。
- 20-24年，在字节跳动，见证TikTok政策的几起几落。
以这个时间线进行观察和讲述，辅以其他案例



## 目录结构（按流程编号）
- `01_brief_inputs/`  
  - `brief.md`：主题、痛点、数据诉求的原始输入。  
  - `outline_raw.md`：运行 `01_brief_inputs/outline_prompt.md` 的初稿提纲。  
  - `brief_review.md`：评语与 TODO，确认后同步到正式提纲。  
  - `outline.md`：确认版五章结构与视觉/互动占位。  
  - `gap_list.md`：缺失数据/案例/视觉清单及负责人。
- `02_synthesis/`  
  - `cases.md`：案例矩阵（主体/时间/动作/数据/结果/来源）。  
  - `cases_review.md`：给评审补充或勾选的版本。  
  - `insights.md`：章节命题、数据引用、待核问题。  
  - `insights_review.md`：评语与追问。
- `03_chapter_iterations/`  
  - `segments/segment_<n>.md`：每章段落骨架。  
  - `segments/segment_<n>_review.md`：对应段落的批注版。  
  - `chapters/stage_01/chapter_<n>.md`：最新章节草稿。  
  - `chapters/stage_01/chapter_<n>_qa.md`：章/节级质检记录。
- `04_article_delivery/`  
  - `article.md`：合并后的 V5 成稿（约 3,700 字）。  
  - `article_review.md`：供审稿与局部修改的副本。  
  - `visual_plan.md`：5 处视觉/互动设计说明。  
  - `visual_plan_review.md`：设计与运营反馈区。
- `05_quality_prompts/`  
  - `qa.md`：全文/章节/小节级质检表。  
  - `qa_review.md`：审稿反馈。  
  - `prompts.md`：本轮提示词与流程调整。  
  - `prompts_review.md`：提示词修改确认。

## 提示词索引
- `01_brief_inputs/outline_prompt.md`：提纲生成提示词（输出贴入 `outline_raw.md`）。
- `02_synthesis/case_prompt.md`、`02_synthesis/synthesis_prompt.md`：案例与洞察梳理提示词。
- `03_chapter_iterations/chapter_prompt.md`：逐章写作提示词。
- `04_article_delivery/article_prompt.md`：全文生成提示词。
- `05_quality_prompts/quality_checklists.md`：质检与自查清单。
